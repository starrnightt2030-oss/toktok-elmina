# توكتوك الميناء — Alexandria Port Simulator

لعبة توكتوك ثلاثية الأبعاد في المتصفح، مستوحاة من ميناء الإسكندرية وترسانتها ومركز التدريب.

## التشغيل على جهازك
```bash
npm install
npm run dev      # يفتح اللعبة على http://localhost:5173
npm run build    # نسخة النشر في dist/
```

## هيكل المشروع
| المسار | المحتوى |
| --- | --- |
| `index.html` | الواجهة والقوائم |
| `src/main.js` | العالم، المهام، الراديو، الحوار، الواجهة |
| `src/vehicle.js` | فيزياء القيادة (Rapier): مساعدين، غيارات، فرامل يد، بنزين |
| `public/models/tuk.glb` | نموذج التوكتوك |
| `tools/build_tuk.py` | سكريبت Blender اللي بيبني نموذج التوكتوك (`npm run model`) |
| `tools/sim_test.mjs` | اختبار القيادة من غير متصفح: `node tools/sim_test.mjs` |

## النشر
أي `push` على فرع `main` بيبني اللعبة وينشرها على GitHub Pages تلقائيًا
(Settings ← Pages ← Source: **GitHub Actions**).

## التحكم
- الكمبيوتر: `W` بنزين · `S` فرامل/رجوع · `A` `D` دركسيون · `Shift` تيربو · `Space` فرامل يد · `H` كلاكس · `R` راديو · `C` كاميرا
- دراع التحكم: الزناد اليمين بنزين، الشمال فرامل، `A` فرامل يد، `B` تيربو
- الموبايل: جويستيك أو إمالة الموبايل (من القائمة)
